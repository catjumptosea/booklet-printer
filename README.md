# Booklet Printer

一个在浏览器本地处理 PDF 小册子的工具。上传 PDF 后会自动补齐所需页面、完成骑马订拼版，并提供翻页视图和纸张视图预览。确认无误后可以导出双面打印 PDF，或分别导出正面、反面两个 PDF。

## 功能

- PDF 本地解析与自动空白页补齐
- 骑马订小册子拼版
- A4 模式下可选择 A5 小册子或 A6 小册子
- 翻页视图与纸张视图预览
- 自定义空白页插入位置
- 导出双面打印 PDF
- 导出手动双面打印所需的正面、反面 PDF

## A6 小册子

选择「A6 小册子」后，每张 A4 纸保持横向，一面排 2×2。打印后先沿水平中线裁成上下两条 297 × 105 mm 裁片；再沿短边中线对折，把上半裁片嵌套进下半裁片，按纸张顺序叠放并从折缝骑马订。最终成品是一本 A6 小册子，页面尺寸为 148.5 × 105 mm。

## 本地开发

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

预览生产构建：

```bash
pnpm preview
```

PDF 文件不会上传到服务器，所有解析、预览和导出都在浏览器内完成。
