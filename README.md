# Booklet Printer

一个在浏览器本地处理 PDF 小册子的工具。上传 PDF 后会自动补齐 4 的倍数页面、完成骑马订拼版，并提供翻页视图和纸张视图预览。确认无误后可以导出双面打印 PDF，或分别导出正面、反面两个 PDF。

## 功能

- PDF 本地解析与自动空白页补齐
- 骑马订小册子拼版
- 翻页视图与纸张视图预览
- 自定义空白页插入位置
- 导出双面打印 PDF
- 导出手动双面打印所需的正面、反面 PDF

## 本地开发

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

预览生产构建：

```bash
pnpm preview
```

PDF 文件不会上传到服务器，所有解析、预览和导出都在浏览器内完成。
